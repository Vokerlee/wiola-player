# Layout protocol fixtures

The same known documentTabs ID migrates only in v1. In v2 an ID alone does not attach a view. A schema-1 session envelope contains a version-2 layout and selected preset identity; the envelope schema and layout version are different contracts. Duplicate component IDs are invalid. A future session blocks acceptance and preserves original bytes.
