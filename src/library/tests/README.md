# Catalog tests

These cases test the [library owner](../README.md): distinct identities and occurrences, metadata/tag rules, query matching, repository transactions and location reconciliation. They link the catalog target and use controlled facts or scoped files where native observations are part of the current contract.

The owner registers these tests when `WIOLA_BUILD_TESTS` is enabled. Shared portable collaborators remain under the repository test root; Qt storage/schema tests stay with the [Qt storage adapter](../../qt/storage/tests).
